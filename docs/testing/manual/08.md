# Kézi ellenőrzés – 08. feladat (megosztás, szerep szerinti nézetek)

A lépéseket a fejlesztő hajtja végre böngészőben (az agent nem tud böngészőt kezelni). Az elvárt
eredmények a szerver üzeneteit szó szerint idézik (`Notes.Api/Services/ShareService.cs`,
`Notes.Api/Services/NoteAccessService.cs`); a kliens üres felhasználónévnél ugyanazt a szöveget adja
(`notes-web/src/notes/limits.ts`). A szerepbélyegző nagybetűvel jelenik meg (pl. „OLVASÓ”).

## Előkészítés
1. Backend (1. terminál, a repó gyökerében): `dotnet run --project Notes.Api --launch-profile http` → `http://localhost:5098`
2. Frontend (2. terminál): `cd notes-web`, `npm run dev` → `http://localhost:5173`
3. Két böngészőprofil kell (pl. Chrome: két külön profil, vagy egy normál és egy vendég ablak):
   - **1. profil** – a tulajdonos, **T** (pl. `teszt_t8`)
   - **2. profil** – a címzett, **C** (pl. `teszt_c8`)
   A jelszó mindkettőnél `Jelszo123`. Mindkét név legyen új (még nem regisztrált).
4. A böngészőablakok legyenek legalább 1024 px szélesek (lista és szerkesztő egymás mellett), kivéve a 27. lépést.
5. A PowerShell-lépések (12., 21.) parancsai lent, a „PowerShell-parancsok” részben vannak. A JSON-törzset
   UTF-8 bájtokként küldik (`[Text.Encoding]::UTF8.GetBytes(...)`, `application/json; charset=utf-8`), mert a
   Windows PowerShell 5.1 a szöveges törzset Latin-1 kódolással küldené, és az ékezetes betűk miatt a kérés
   400-at kapna (a 06. kézi próbájában derült ki).

## PowerShell-parancsok
A backend fusson. A `teszt_c8` helyére a választott **C** nevet, a `$id` értékéhez a jegyzet azonosítóját írd.
Ha a parancsokat `.ps1` fájlba mented, a fájlt UTF-8 BOM-mal mentsd, különben az 5.1 rosszul olvassa be az
ékezeteket.

### Közös rész (egyszer kell, mindkét lépés előtt)
```powershell
$api = "http://localhost:5098/api"
# Sends the request; prints "<label>: <status code> <detail>". The JSON body goes as UTF-8 bytes.
function Test-Api($Label, $Method, $Uri, $Json = $null) {
  $params = @{ Method = $Method; Uri = $Uri; Headers = $script:h; UseBasicParsing = $true }
  if ($Json) {
    $params.ContentType = "application/json; charset=utf-8"
    $params.Body = [Text.Encoding]::UTF8.GetBytes($Json)
  }
  try {
    $r = Invoke-WebRequest @params
    "${Label}: $($r.StatusCode)"
  } catch {
    $status = [int]$_.Exception.Response.StatusCode
    $detail = ($_.ErrorDetails.Message | ConvertFrom-Json).detail
    "${Label}: $status $detail"
  }
}
$login = Invoke-RestMethod -Method Post "$api/auth/login" -ContentType "application/json; charset=utf-8" `
  -Body ([Text.Encoding]::UTF8.GetBytes('{"userName":"teszt_c8","password":"Jelszo123"}'))
$script:h = @{ Authorization = "Bearer $($login.token)" }
$id = "<a jegyzet azonosítója>"
```

### 12. lépés (C olvasó)
```powershell
Test-Api "PUT /notes" Put "$api/notes/$id" '{"title":"Olvasó próbája","content":"átírva"}'
Test-Api "DELETE /notes" Delete "$api/notes/$id"
Test-Api "POST /shares" Post "$api/notes/$id/shares" '{"userName":"teszt_c8","role":"Editor"}'
```

### 21. lépés (C szerkesztő)
```powershell
Test-Api "DELETE /notes" Delete "$api/notes/$id"
Test-Api "POST /shares" Post "$api/notes/$id/shares" '{"userName":"teszt_c8","role":"Viewer"}'
Test-Api "PUT /folder" Put "$api/notes/$id/folder" '{"folderId":null}'
```
(A token a belépéskor jön létre; ha a 12. és a 21. lépés között lejárt, futtasd újra a közös részt.)

## Eredmény
- Dátum: 2026-11-19
- Böngésző: Google Chrome és Mozilla Firefox (a két szerepet, T-t és C-t, két külön böngészőben futtattam);
  a PowerShell-lépések Windows PowerShell 5.1-ben
- Sikertelen lépések: nincs; mind a 27 lépés az elvárt eredményt adta
- Talált hibák: termékhiba nincs. A 12. lépés PowerShell-segédfüggvénye (`Test-Api`) Windows PowerShell 5.1 alatt nem tudta kiolvasni a hibaválasz törzsét (`$_.ErrorDetails.Message` üres volt), ezért a `detail` helyett `ConvertFrom-Json` hibát írt ki; a státuszkódok (403) helyesek voltak. A függvényt javítottam: üres `ErrorDetails` esetén a válasz adatfolyamából olvassa ki a törzset; a javított változattal a 12. és a 21. lépés a `detail` üzenetet is kiírta. A fenti „Közös rész” már a javított függvényt tartalmazza.
