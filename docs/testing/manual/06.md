# Kézi ellenőrzés – 06. feladat (frontend váz, belépés, lista)

A lépéseket a fejlesztő hajtja végre böngészőben (az agent nem tud böngészőt kezelni). Az elvárt
eredmények a szerver üzeneteit szó szerint idézik (`Notes.Api/Services/AuthService.cs`).

## Előkészítés
1. A JWT-kulcs be van állítva (egyszer kell): `dotnet user-secrets set "Jwt:Key" "<legalább 32 bájtos titok>" --project Notes.Api`
2. Adatbázis: `dotnet ef database update --project Notes.Api`
3. Backend (1. terminál, a repó gyökerében): `dotnet run --project Notes.Api --launch-profile http` → `http://localhost:5098`
4. Frontend (2. terminál): `cd notes-web`, `npm install`, `npm run dev` → `http://localhost:5173`
5. A tesztekhez két új felhasználónév kell, amelyek még nem léteznek, a továbbiakban **A** (pl. `teszt_a1`) és **B**
   (pl. `teszt_b1`). A jelszó mindkettőnél `Jelszo123`.

### A 18. lépés parancsa (PowerShell, a backend fusson)
```powershell
$api = "http://localhost:5098/api"
$b = Invoke-RestMethod -Method Post "$api/auth/register" -ContentType "application/json" `
  -Body '{"userName":"teszt_b1","password":"Jelszo123"}'
$h = @{ Authorization = "Bearer $($b.token)" }
$note = Invoke-RestMethod -Method Post "$api/notes" -Headers $h -ContentType "application/json" `
  -Body '{"title":"B titkos aktája","content":"Megosztott tartalom"}'
Invoke-RestMethod -Method Post "$api/notes/$($note.id)/shares" -Headers $h -ContentType "application/json" `
  -Body '{"userName":"teszt_a1","role":"Viewer"}'
```
(Ha más neveket választottál, a `teszt_b1` / `teszt_a1` helyére azokat írd. Az ékezetes cím miatt PowerShell 7 ajánlott.)
