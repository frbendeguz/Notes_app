# Kézi ellenőrzés – 07. feladat (szerkesztő és mappák)

A lépéseket a fejlesztő hajtja végre böngészőben (az agent nem tud böngészőt kezelni). Az elvárt
eredmények a szerver üzeneteit szó szerint idézik (`Notes.Api/Services/NoteService.cs`, `FolderService.cs`,
`Errors/ValidationFailedException.cs`); a kliensoldali ellenőrzés ugyanezeket a szövegeket használja
(`notes-web/src/notes/limits.ts`).

## Előkészítés
1. Backend (1. terminál, a repó gyökerében): `dotnet run --project Notes.Api --launch-profile http`
2. Frontend (2. terminál): `cd notes-web`, `npm run dev` → `http://localhost:5173`
3. Egy új felhasználó kell, a továbbiakban **C** (pl. `teszt_c1`, jelszó `Jelszo123`): regisztráld a
   „Fiók létrehozása” oldalon. A 33. lépéshez a 06-os **A** felhasználó (`teszt_a1`) kell, akivel **B** megosztott
   egy jegyzetet.
4. A hosszú szövegeket PowerShell teszi a vágólapra (csak ASCII betű, ezért kódolási gond nincs; JSON-törzset
   ez a kézi próba nem küld):
   - 100 / 101 karakteres cím: `Set-Clipboard -Value ('c' * 100)` / `Set-Clipboard -Value ('c' * 101)`
   - 10 000 / 10 001 karakteres szöveg: `Set-Clipboard -Value ('s' * 10000)` / `Set-Clipboard -Value ('s' * 10001)`
   - 51 karakteres mappanév: `Set-Clipboard -Value ('m' * 51)`
5. A böngészőablak legyen legalább 1024 px széles (a lista és a szerkesztő egymás mellett), kivéve a 34. lépést.
